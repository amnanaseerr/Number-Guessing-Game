# 🎮 Number Guessing Game – C++

A simple **Number Guessing Game** written in **C++** where the player has to guess a randomly generated number between 1 and 100.

## 🚀 Features

- The program generates a random number between 1 and 100.
- The player makes guesses, and the program provides feedback on whether the guess is too high or too low.
- The game continues until the player guesses the correct number.
- The total number of guesses is tracked and displayed when the correct number is guessed.
- 
## 🛠️ Technologies Used

- **C++** – Language used to implement the game logic.

   ```bash
   g++ -o guessing_game guessing_game.cpp
